# Pixelforge

Піксель-арт студія в браузері: редактор із шарами та анімацією, експорт у PNG/GIF,
імпорт PNG, акаунти та публічна галерея з лайками.

Курсовий проєкт з фронтенд-розробки. Фронтенд — React + TypeScript, бекенд — FastAPI + SQLite.

```
┌──────────────────────────────┐        /api/*        ┌──────────────────────────┐
│  Frontend (React, Vite)      │  ─────────────────▶  │  Backend (FastAPI)       │
│  редактор, галерея, профілі  │  ◀─────────────────  │  JWT, роботи, лайки      │
│  чернетка в localStorage     │       JSON / PNG     │  SQLite (один файл)      │
└──────────────────────────────┘                      └──────────────────────────┘
```

## Можливості

**Редактор**
- олівець, гумка, заливка (Shift — замінити колір у всьому шарі), піпетка, лінія, прямокутник, еліпс, рука;
- розмір пензля 1–4, дзеркальне малювання, заповнені фігури, Shift — рівні лінії/квадрат/коло;
- полотно від 1×1 до 128×128, масштаб колесом і щипком, сітка, координати курсора;
- шари (до 16): видимість, прозорість, порядок, дублювання, перейменування;
- анімація (до 120 кадрів): таймлайн, калька попереднього кадру, програвання з FPS 1–30;
- undo/redo на 100 кроків, гарячі клавіші, що працюють і на українській розкладці;
- палітри PICO-8, Sweetie 16, Game Boy, Grayscale і власна, останні кольори;
- експорт: PNG (×1…×32), спрайтшит, анімований GIF (власний кодувальник LZW, без бібліотек);
- чернетка автоматично зберігається в браузері — нічого не губиться при перезавантаженні.

**Акаунти та галерея**
- реєстрація з унікальним ніком (без урахування регістру, кирилиця теж працює) і паролем, JWT;
- «Мої роботи»: приватні/публічні, перейменування, дублювання, видалення, пошук;
- завантаження PNG двома способами: **у редактор** (пікселізація до 16…128) або **у галерею як картинку**;
- публічна галерея: сортування «Нові/Популярні», пошук, лайки, перегляд з анімацією, ремікс чужої роботи;
- профіль користувача зі статистикою.

**Якість фронтенду**
- темна/світла/системна тема, перемикач мови UA/EN;
- адаптивний інтерфейс (на телефоні — панелі в шторці, щипок для масштабу);
- доступність: фокус-кільця, ролі ARIA, керування меню з клавіатури, пастка фокусу в модалках,
  `prefers-reduced-motion`;
- code splitting (редактор вантажиться окремим чанком), рендер полотна без ре-рендерів React.

## Швидкий старт

### Варіант 1 — Docker (усе однією командою)

```bash
cp .env.example .env          # і заміни JWT_SECRET
docker compose up --build
```

- сайт: http://localhost:8080
- Swagger API: http://localhost:8080/api/docs

### Варіант 2 — локально (для розробки)

Потрібні **Python 3.11+** і **Node.js 20+**.

```bash
# Термінал 1 — бекенд
cd backend
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload      # http://localhost:8000/api/docs

# Термінал 2 — фронтенд
cd frontend
npm install
npm run dev                        # http://localhost:5173
```

Vite сам проксіює `/api` на `localhost:8000`, тож CORS налаштовувати не треба.

Детально, включно з PyCharm, — у [docs/SETUP.md](docs/SETUP.md).

### Тести

```bash
cd backend && pytest -v           # API: реєстрація, права доступу, лайки, завантаження PNG
cd frontend && npm test           # алгоритми: заливка, Брезенхем, RLE, GIF, кольори
cd frontend && npm run typecheck  # перевірка типів TypeScript
```

## Структура

```
pixelforge/
├─ backend/                 FastAPI + SQLAlchemy + SQLite
│  ├─ app/
│  │  ├─ main.py            точка входу, CORS, підключення роутерів
│  │  ├─ config.py          налаштування зі змінних оточення
│  │  ├─ database.py        engine, сесії, створення таблиць
│  │  ├─ models.py          User, Artwork, Like
│  │  ├─ schemas.py         Pydantic-схеми запитів/відповідей
│  │  ├─ security.py        bcrypt + JWT
│  │  ├─ deps.py            залежності: сесія БД, поточний користувач
│  │  ├─ routers/           auth, users, artworks, gallery
│  │  └─ services/          запити до робіт, розбір PNG
│  ├─ tests/                pytest
│  └─ Dockerfile
├─ frontend/                React 18 + TypeScript + Vite + Tailwind
│  ├─ src/
│  │  ├─ app/               App, роутер, каркас сторінки
│  │  ├─ pages/             сторінки (Home, Editor, Gallery, MyWorks, Profile, Auth, 404)
│  │  ├─ features/
│  │  │  ├─ editor/         модель документа, стор, полотно, панелі, експорт
│  │  │  ├─ gallery/        картки, перегляд, лайки, пагінація
│  │  │  ├─ upload/         завантаження PNG
│  │  │  └─ home/           жива сітка на головній, спрайти
│  │  ├─ shared/
│  │  │  ├─ lib/            чисті алгоритми без React (+ тести)
│  │  │  ├─ ui/             Modal, Menu, IconButton, Switch, Toaster…
│  │  │  ├─ api/            HTTP-клієнт і типи API
│  │  │  └─ i18n/           переклади UA/EN
│  │  ├─ store/             auth, settings, toasts (Zustand)
│  │  └─ styles/            дизайн-токени і компонентні класи
│  ├─ nginx.conf, Dockerfile
├─ docs/                    документація
├─ .run/                    готові конфігурації запуску для PyCharm
└─ docker-compose.yml
```
