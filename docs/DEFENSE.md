# Захист проєкту

## Сценарій демонстрації (≈ 7 хвилин)

1. **Головна.** Спрайт «малюється» сам — це єдина автоматична анімація на сайті.
   Домалювати щось на сітці → «Домалювати в редакторі».
2. **Редактор.** Показати інструменти з клавіатури (`B`, `G`, `U` + `Shift`), дзеркало `M`,
   два шари з різною прозорістю, undo/redo.
3. **Анімація.** Додати кадр, увімкнути кальку, домалювати рух, `Enter` — програвання.
4. **Експорт.** `Ctrl+E` → GIF ×8 → відкрити файл.
5. **Збереження.** `Ctrl+S` без акаунта → редірект на реєстрацію → жива перевірка ніку →
   повернення в редактор → збереження → URL `/editor/:id`.
6. **Галерея.** Опублікувати, відкрити галерею, лайкнути, переглянути анімацію.
7. **Імпорт PNG.** Завантажити фото → пікселізація 32×32 → відкрити в редакторі.
8. **Адаптив і тема.** Перемкнути темну тему, мову EN, звузити вікно (панелі стають шторкою).
9. Наостанок — Swagger на `/api/docs`.

## Що підкреслити

- **Фронтенд у пріоритеті:** власна дизайн-система (токени, піксельна тінь, два шрифти з ролями),
  світла/темна тема без спалаху, повна доступність з клавіатури, адаптив, i18n з перевіркою типів.
- **Нетривіальні алгоритми написані вручну:** Брезенхем, scanline-заливка, альфа-композиція шарів,
  RLE, кодувальник GIF з LZW — і покриті тестами.
- **Продуктивність:** полотно малюється поза React через `requestAnimationFrame`;
  редактор вантажиться окремим чанком.
- **Архітектура:** feature-based папки, чисті функції окремо від компонентів, незмінний стан → дешевий undo.
- **Бекенд мінімальний, але правильний:** bcrypt, JWT, права доступу, каскадне видалення, тести.

## Можливі питання

**Чому React, а не Vue/Angular?**
Найпоширеніший стек, велика екосистема; хуки добре лягають на редактор, де багато незалежних панелей.
Плюс TypeScript strict ловить помилки на етапі збірки.

**Навіщо Zustand, якщо є Context?**
Context перерендерює всіх споживачів при будь-якій зміні. У редакторі стан змінюється десятки разів
на секунду, а Zustand дає підписку на конкретне поле через селектор і доступ до стану поза React
(в обробниках миші й гарячих клавішах).

**Як працює undo/redo?**
Документ незмінний: кожна дія створює новий об'єкт, у якому замінено лише один масив пікселів.
Історія — масив посилань на попередні документи (до 100). Увесь штрих мишею — одна дія.

**Як малюється лінія, якщо миша рухається швидко і пропускає пікселі?**
Між попередньою і поточною позицією курсора будується пряма алгоритмом Брезенхема — він дає
безперервну лінію пікселів без дробових обчислень.

**Як працює заливка?**
Scanline flood fill: від точки розширюємося вліво-вправо до межі кольору, фарбуємо відрізок
і кладемо в стек пікселі над і під ним. Стек замість рекурсії — щоб не переповнити стек викликів.

**Як зберігаються малюнки?**
Колір пікселя — одне число `0xRRGGBBAA`. Перед відправкою кожен шар стискається RLE (пари
«скільки разів — який колір»). На сервері — JSON-текст у SQLite і PNG-прев'ю як BLOB.

**Як зроблено GIF без бібліотек?**
Будуємо спільну палітру (до 255 кольорів + прозорий), кожен кадр — масив індексів кольорів,
який стискається LZW зі змінною довжиною коду (від 3 до 12 біт), блоки по 255 байт.
Блок NETSCAPE2.0 робить анімацію нескінченною.

**Чому пароль, а не просто нік?**
Без пароля будь-хто увійшов би під чужим ніком і видалив чужі роботи.
Пароль хешується bcrypt із сіллю — у базі його немає у відкритому вигляді.

**Що в JWT і чому він безпечний?**
Лише `sub` (id користувача) і `exp`. Токен підписаний секретом сервера (HS256) — змінити id
без секрету неможливо, підпис не зійдеться. Термін дії — 7 днів.

**Чому нік унікальний без урахування регістру і як це з кирилицею?**
Порівнюється `casefold()` від ніку, який зберігається в окремому полі з UNIQUE-індексом.
Вбудований `lower()` у SQLite працює лише з латиницею, тому нормалізація робиться в Python.

**Як захищені приватні роботи?**
На запит чужої приватної роботи сервер відповідає `404`, а не `403`, — так навіть не видно,
що така робота існує. Прев'ю приватних робіт фронтенд тягне через `fetch` з токеном,
бо звичайний `<img>` не може надіслати заголовок авторизації.

**Чому гарячі клавіші працюють на українській розкладці?**
Використовується `event.code` (фізична клавіша, наприклад `KeyB`), а не `event.key` (символ «и»).

**Що буде, якщо закрити вкладку посеред малювання?**
Чернетка автоматично пишеться в `localStorage` через пів секунди після кожної зміни
і ще раз — перед закриттям сторінки.

**Як зробили темну тему без миготіння?**
Невеликий скрипт в `index.html` читає налаштування з `localStorage` і ставить клас `.dark`
до того, як завантажиться React. Кольори — CSS-змінні, Tailwind бере їх через `rgb(var(--…))`.

**Що з доступністю?**
Ролі ARIA (dialog, menu, switch, radiogroup), пастка фокусу в модалках, керування меню
стрілками, видимий фокус, підписи до всіх іконкових кнопок, `prefers-reduced-motion`.

**Чому SQLite, а не PostgreSQL?**
Для навчального проєкту — один файл без сервера. Доступ іде через SQLAlchemy ORM,
тож перехід на PostgreSQL — це зміна `DATABASE_URL`.

**Що б ви покращили?**
Міграції Alembic, refresh-токени в httpOnly-cookie, інструмент виділення й переміщення,
коментарі, спільне редагування через WebSocket, PWA для роботи офлайн.
