# Фронтенд

**Стек:** React 18, TypeScript (strict), Vite 5, Tailwind CSS 3, Zustand 5, React Router 6,
Framer Motion, lucide-react (іконки), Vitest (тести), шрифти Silkscreen і Rubik з `@fontsource`.

## Структура `src/`

```
src/
├─ main.tsx                 підключення шрифтів, стилів, рендер <App/>
├─ app/
│  ├─ App.tsx               тема, мова, перевірка сесії, автозбереження чернетки
│  ├─ router.tsx            маршрути; редактор — lazy (окремий JS-чанк)
│  ├─ AppShell.tsx          шапка, підвал, Suspense, лого
│  └─ RequireAuth.tsx       захист /me → редірект на /login?next=...
├─ pages/                   «тонкі» сторінки: збирають фічі докупи
├─ features/
│  ├─ editor/               усе про редактор (див. нижче)
│  ├─ gallery/              картка роботи, лайк, перегляд, пагінація
│  ├─ upload/               діалог завантаження PNG
│  └─ home/                 жива сітка 16×16, текстові спрайти
├─ shared/
│  ├─ lib/                  алгоритми без React: колір, геометрія, заливка, RLE, GIF, зображення
│  ├─ ui/                   Modal, Menu, ConfirmDialog, IconButton, Switch, Segmented, Toaster…
│  ├─ api/                  client.ts (fetch + JWT + помилки), types.ts (типи відповідей)
│  ├─ i18n/                 uk.ts, en.ts, хук useT()
│  └─ hooks/                useDebounced
├─ store/                   auth, settings, toasts
└─ styles/index.css         дизайн-токени та компонентні класи
```

## Маршрути

| Шлях | Сторінка | Доступ |
|---|---|---|
| `/` | Головна з живою сіткою | усі |
| `/editor` | Редактор (локальна чернетка) | усі |
| `/editor/:id` | Редактор з роботою з сервера; чужа публічна робота відкривається як ремікс | усі |
| `/gallery?sort=popular&q=...` | Публічна галерея | усі |
| `/me` | Мої роботи + налаштування акаунта | лише залогінені |
| `/u/:username` | Профіль автора | усі |
| `/login`, `/register` | Вхід / реєстрація (`?next=` — куди повернутись) | усі |
| `*` | 404 | усі |

## Стан застосунку

| Стор | Що зберігає | Де живе |
|---|---|---|
| `features/editor/store.ts` → `useEditor` | документ, вибраний кадр/шар, інструмент, кольори, історія, метадані роботи, масштаб | пам'ять + чернетка в `localStorage` (`pixelforge:draft:v1`) |
| `useCursor` | координати курсора над полотном | пам'ять (окремо, щоб рух миші не чіпав інші компоненти) |
| `store/auth.ts` → `useAuth` | JWT і профіль | `localStorage` (`pixelforge:auth`) |
| `store/settings.ts` → `useSettings` | тема, мова | `localStorage` (`pixelforge:settings`) |
| `store/toasts.ts` → `useToasts` | спливаючі повідомлення | пам'ять |

Компоненти підписуються на мінімальні шматки стану селекторами
(`useEditor((s) => s.doc.layers)`), тож, наприклад, зміна кольору не перерендерює таймлайн.

## Редактор зсередини

### Модель документа (`features/editor/model.ts`)

```ts
interface PixelDoc {
  width: number;            // 1…128
  height: number;
  fps: number;              // 1…30
  layers: LayerMeta[];      // [0] — найнижчий шар
  frames: Frame[];
}
interface LayerMeta { id; name; visible; opacity }   // спільні для всіх кадрів
interface Frame { id; cels: Record<layerId, number[]> } // пікселі шару в кадрі
```

Колір пікселя — одне 32-бітне число `0xRRGGBBAA`, `0` — прозорий (`shared/lib/color.ts`).

Усі функції моделі чисті: `withCel(doc, frame, layer, pixels)` повертає **новий** документ,
у якому замінено лише один масив. Інші шари й кадри — ті самі об'єкти (structural sharing).

`compositeFrame(doc, i)` зводить видимі шари з урахуванням прозорості (альфа-композиція
*source-over*) в RGBA-буфер. Його використовують полотно, мініатюри, експорт і прев'ю.

### Історія (undo/redo)

- `past: PixelDoc[]`, `future: PixelDoc[]`, ліміт 100 кроків.
- Штрих мишею — це **одна** дія: `beginStroke()` запам'ятовує документ на початку,
  `setCel()` під час руху оновлює документ без запису в історію, `endStroke()` кладе
  початковий документ у `past` (якщо щось змінилось).
- Повзунок прозорості й поле FPS «склеюють» серію змін в одну дію (ключ коалесценції, 800 мс).
- Оскільки документи незмінні, знімок історії коштує лише кілька посилань.

### Рендер полотна (`PixelCanvas.tsx`)

1. `ResizeObserver` стежить за розміром контейнера; canvas масштабується з урахуванням `devicePixelRatio`.
2. `useEditor.subscribe(...)` → `requestAnimationFrame(draw)` — не більше одного кадру на 16 мс.
3. `draw()` малює: шахову підкладку (`CanvasPattern`) → кальку попереднього кадру (28 % непрозорості) →
   композит поточного кадру (через offscreen canvas розміром з документ і `drawImage` зі
   `imageSmoothingEnabled = false`) → сітку (тонка кожен піксель, товща кожні 8) → рамку → контур пензля.
4. Кольори теми читаються з CSS-змінних; `MutationObserver` на `<html class>` оновлює їх при зміні теми.

### Жести

| Дія | Результат |
|---|---|
| ЛКМ | малювання основним кольором |
| ПКМ | малювання додатковим кольором |
| Alt + клік | тимчасова піпетка |
| Середня кнопка / Пробіл / інструмент «Рука» | панорама |
| Колесо | масштаб до курсора (рівні 1, 2, 3, 4, 5, 6, 8 … 80) |
| Ctrl + колесо / щипок на тачпаді | плавний масштаб |
| Два пальці (тач) | щипок: масштаб + зсув; почата лінія скасовується |

Усе зроблено на Pointer Events з `setPointerCapture`, тож миша, перо й палець працюють однаково.

### Алгоритми (`shared/lib/`)

| Файл | Що всередині |
|---|---|
| `geometry.ts` | **Брезенхем** для ліній (і для з'єднання точок швидкого руху миші), прямокутник, еліпс через рівняння `(x/rx)² + (y/ry)² ≤ 1`, прив'язка до 45° і квадрата з Shift |
| `floodFill.ts` | **Scanline flood fill** зі стеком замість рекурсії (не падає на 128×128), 4-зв'язність; заміна кольору в усьому шарі |
| `rle.ts` | Run-Length Encoding для збереження: `[0,0,0,5,5] → [3,0, 2,5]` |
| `gif.ts` | **Кодувальник GIF89a**: спільна палітра (≤255 кольорів + прозорий; інакше квантування 6×7×6), LZW-стиснення зі змінною довжиною коду та скиданням словника, NETSCAPE2.0 для зациклення |
| `image.ts` | масштабування без розмиття (nearest neighbor), RGBA → PNG, пікселізація картинки, перевірка сигнатури PNG |
| `color.ts` | пакування RGBA в число, HEX ↔ число |

Тести — `shared/lib/lib.test.ts` (`npm test`).

### Гарячі клавіші (`shortcuts.tsx`)

Обробник використовує `KeyboardEvent.code` (фізична клавіша), а не `key` (символ),
тому `B` вмикає олівець і тоді, коли активна українська розкладка (де ця клавіша друкує «И»).
Клавіші ігноруються, коли фокус у полі вводу або відкрите модальне вікно.
Повний список — у [USER_GUIDE.md](USER_GUIDE.md).

### Збереження

- **Локально:** `startDraftAutosave()` підписується на стор і з затримкою 500 мс пише
  серіалізований документ у `localStorage`. Відновлення — при завантаженні модуля, до першого рендеру.
- **На сервер:** `useSaveArtwork()`; якщо робота була видалена чи чужа (`404/403`) — створюється нова.
- Перед відкриттям іншої роботи при незбережених змінах показується підтвердження.

## Імпорт PNG (`features/upload/UploadDialog.tsx`)

1. Файл перевіряється за **сигнатурою** `89 50 4E 47…`, а не за розширенням.
2. `createImageBitmap` декодує картинку.
3. Режим **«У редактор»**: картинка малюється на canvas розміром 16/32/64/128 по довшій стороні
   (зі згладжуванням для фото або без — для вже збільшеного піксель-арту), пікселі з альфою < 16
   стають прозорими. Прев'ю перераховується наживо.
4. Режим **«У мої роботи»**: файл ≤ 2 МБ відправляється `multipart/form-data` на `/api/artworks/upload`.

Завантажену картинку з галереї теж можна відкрити в редакторі — вона пройде той самий шлях пікселізації.

## Дизайн-система

Візуальна ідея — «нічна майстерня піксель-артиста»: глибокий індиго замість чорного,
золото ігрової монетки як головний акцент і бірюза «слайма» як другий колір.
Фірмовий прийом — **жорстка піксельна тінь** без розмиття (`shadow-pixel: 3px 3px 0`) на головних кнопках,
модалках і меню; при натисканні кнопка «втискається» в тінь.

| Токен | Світла | Темна | Де |
|---|---|---|---|
| `--bg` | `#EEEDF5` | `#1B1A2E` | фон сторінки |
| `--surface` | `#FFFFFF` | `#25233D` | панелі, картки |
| `--ink` | `#1E1B2E` | `#ECEAF6` | текст |
| `--accent` | `#F2B705` | `#FFC828` | головні кнопки, виділення |
| `--teal` | `#14968A` | `#2EC4B6` | статуси «збережено», перемикачі |
| `--danger` | `#C8373E` | `#F06268` | видалення, помилки |

Токени — CSS-змінні у форматі `R G B`, підключені в `tailwind.config.js`, тому працюють
модифікатори прозорості: `bg-accent/20`. Темна тема — клас `.dark` на `<html>`, який ставиться
ще до завантаження React (скрипт в `index.html`), тож немає «спалаху» світлої теми.

**Шрифти:** Silkscreen — піксельний, лише для заголовків і логотипа; Rubik — для інтерфейсу.

**Рух:** одна оркестрована анімація — спрайт на головній «малюється» рядок за рядком.
Решта анімацій лише відповідають на дії: відкриття модалок, меню, тостів, «підстрибування» лайка.
При `prefers-reduced-motion` анімації вимикаються (і в CSS, і через `MotionConfig` у Framer Motion,
і спрайт одразу показується повністю).

## Доступність

- усі іконкові кнопки мають `aria-label` і підказку з гарячою клавішею;
- видиме кільце фокусу (`:focus-visible`) кольору акценту;
- модальні вікна: `role="dialog"`, `aria-modal`, пастка фокусу, Esc, повернення фокусу;
- меню: `role="menu"`, стрілки ↑ ↓, Home, End, Esc;
- перемикачі — `role="switch"`, сегменти — `role="radiogroup"`;
- тости — `aria-live`, помилки — `role="alert"`;
- `lang` у `<html>` змінюється разом з мовою інтерфейсу.

## Інтернаціоналізація

`shared/i18n/uk.ts` — джерело правди: його ключі утворюють тип `TKey`.
`en.ts` має тип `Record<TKey, string>`, тож TypeScript не дасть забути переклад.
Підстановки: `t('auth.welcome', { name })` → «Привіт, {name}!».

## Продуктивність

- редактор — окремий lazy-чанк, головна і галерея вантажаться швидше;
- полотно рендериться поза React, не частіше ніж раз на кадр;
- мініатюри шарів і кадрів перераховуються (`useMemo`) лише коли змінився саме їхній масив;
- зображення в галереї — `loading="lazy"`, публічні прев'ю кешуються браузером (`ETag`, `Cache-Control`);
- пошук із затримкою 350 мс; застарілі відповіді ігноруються (лічильник запитів у `useArtworkList`).
