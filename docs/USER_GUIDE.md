# Інструкція користувача

## Перші кроки

1. Відкрий **Редактор**. Реєстрація для малювання не потрібна — робота зберігається в браузері як чернетка.
2. Малюй лівою кнопкою миші основним кольором, правою — додатковим.
3. Щоб зберегти роботу на сервері, натисни **Зберегти** (або `Ctrl+S`). Якщо ти ще не увійшов,
   тебе перекине на вхід, а після нього — назад у редактор; чернетка нікуди не зникне.
4. Кнопка з глобусом/замком у верхній панелі вирішує, чи буде робота видна в **Галереї**.

## Інструменти

| Інструмент | Клавіша | Як працює |
|---|---|---|
| Олівець | `B` | малює пензлем розміру 1–4 (`[` і `]`) |
| Гумка | `E` | стирає до прозорого |
| Заливка | `G` | заливає зв'язану область; з `Shift` — замінює колір у всьому шарі |
| Піпетка | `I` | бере колір з полотна; також `Alt` + клік будь-яким інструментом |
| Лінія | `L` | з `Shift` — лише горизонталь, вертикаль або 45° |
| Прямокутник | `U` | з `Shift` — квадрат; `F` — заповнений |
| Еліпс | `O` | з `Shift` — коло; `F` — заповнений |
| Рука | `H` | перетягує полотно (те саме — затиснутий `Пробіл` або середня кнопка) |

**Дзеркальне малювання** (`M`) повторює кожен мазок симетрично відносно вертикальної осі —
зручно для персонажів і предметів.

## Кольори

- Клік по кольору палітри — основний колір, правий клік — додатковий. `X` міняє їх місцями.
- Над палітрою — вибір набору: PICO-8, Sweetie 16, Game Boy, Grayscale або **Власна**.
- Поле HEX приймає `#ff004d` або `f04`.
- Кнопка `+` додає поточний колір у власну палітру; навести на колір і натиснути `×` — прибрати.
- Під палітрою — останні використані кольори.

## Шари

- Новий шар з'являється над вибраним. Порядок змінюється стрілками.
- Око — показати/сховати шар (прихований шар не потрапляє в експорт).
- Подвійний клік по назві — перейменувати.
- Повзунок **Прозорість** діє на весь шар.
- Шари спільні для всіх кадрів анімації: якщо сховати «Тінь», вона зникне в кожному кадрі.

## Анімація

- `+` на таймлайні — новий порожній кадр після поточного; кнопка копіювання — копія поточного кадру.
- Стрілки поруч переставляють кадр.
- **Калька** (`Shift+O`) напівпрозоро показує попередній кадр — по ній зручно малювати рух.
- `Enter` — програти/зупинити, `,` і `.` — попередній/наступний кадр, поле FPS — швидкість.

## Імпорт і експорт

**Імпорт PNG** (меню `⋯` → «Імпортувати PNG» або «Завантажити PNG» в «Моїх роботах»):
- *У редактор* — картинка стане піксель-артом 16, 32, 64 або 128 клітинок по довшій стороні.
  Для фото вмикай згладжування, для вже збільшеного піксель-арту — вимикай.
- *У мої роботи* — файл збережеться як є (до 2 МБ) і його можна опублікувати в галереї.

**Експорт** (`Ctrl+E`):
- *PNG* — поточний кадр із прозорим фоном у масштабі ×1…×32 без розмиття;
- *Спрайтшит* — усі кадри в один ряд (формат для Unity, Godot, Phaser);
- *GIF* — анімація по колу з поточним FPS.

## Галерея та профіль

- **Нові / Популярні** — сортування, поле пошуку шукає за назвою.
- Сердечко — лайк (потрібен акаунт).
- Клік по роботі — перегляд з анімацією, інформацією про автора і кнопками:
  «Редагувати» (своя робота), «Зробити ремікс» (чужа — відкриється твоя копія), «Завантажити».
- Нік автора веде на його профіль.

## Мої роботи

Меню `⋯` на картці: відкрити, перейменувати, опублікувати/сховати, дублювати, видалити.
Унизу сторінки — вихід з акаунта і видалення акаунта разом з усіма роботами.

## Усі гарячі клавіші

| Клавіші | Дія |
|---|---|
| `B` `E` `G` `I` `L` `U` `O` `H` | інструменти |
| `[` / `]` | менший / більший пензель |
| `X` | поміняти основний і додатковий колір |
| `M` | дзеркальне малювання |
| `F` | заповнені фігури |
| `Shift` під час малювання | рівна лінія, квадрат, коло |
| `Alt` + клік | піпетка |
| `Delete` | очистити шар у поточному кадрі |
| `+` / `−` / `0` | збільшити / зменшити / вписати в екран |
| `Пробіл` + перетягування | рух полотна |
| `Shift+G` | сітка |
| `Shift+O` | калька |
| `,` / `.` | попередній / наступний кадр |
| `Enter` | програти анімацію |
| `Ctrl+Z` / `Ctrl+Shift+Z` (або `Ctrl+Y`) | скасувати / повторити |
| `Ctrl+S` | зберегти |
| `Ctrl+E` | експорт |
| `Shift+?` | вікно з гарячими клавішами |

Клавіші працюють на будь-якій розкладці (англійській чи українській). На macOS замість `Ctrl` — `Cmd`.
